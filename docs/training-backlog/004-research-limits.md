# 004. [chore] 조사 요청 한도와 중단 처리의 경계 조건 검증

번호: 로컬 #004
상태: Open

유형: technical debt / test

## Background

조사에는 일일 요청 한도, 진행 중 요청 제한, 짧은 간격의 재요청 제한, 오래된 실행의 중단 처리가 있다. 이 제한이 바뀌면 외부 API 호출 수와 사용자가 보는 상태가 달라질 수 있다.

## Current behavior

기준 커밋: `db82c3d`. 기존 자동 테스트는 성공·실패와 직후 재요청을 확인하지만, 서울 날짜 전환의 한도와 오래된 실행 중단, 다른 계획의 동시 요청 경계를 직접 검증하지 않는다.

## Acceptance Criteria

- [ ] 서울 날짜가 바뀌는 시점의 요청 집계 범위를 검증한다.
- [ ] 일일 한도 도달 전후에 허용·거절되는 요청과 외부 호출 여부를 검증한다.
- [ ] 진행 중 조사와 다른 계획의 요청이 겹치는 경우를 검증한다.
- [ ] 시간 초과로 중단된 실행의 표시와 이후 요청 가능 여부를 검증한다.
- [ ] 실제 Gemini 호출이나 분 단위의 대기 없이 반복 실행할 수 있다.

현재 제한 정책을 바꾸거나 다중 인스턴스 제어를 도입하는 작업은 포함하지 않는다.
