# 002. [enhancement] 저장된 조사 결과를 읽지 못한 경우 계획자에게 안내

번호: 로컬 #002
상태: Open
라벨: enhancement

## Background

조사 완료 상태와 결과 본문을 읽을 수 있는지는 별개의 조건이다. 결과를 표시하지 못할 때 사용자가 원인을 알 수 있어야 한다.

## Current behavior

기준 커밋: `db82c3d`의 읽기 처리와 화면 조건에서 확인했다. 성공 상태로 저장된 결과 JSON을 해석하지 못하면 빈 결과로 취급한다. 이때 화면에는 ‘핵심 요약’ 제목과 ‘다시 조사하기’가 남지만 결과를 읽지 못했다는 안내는 없다. 실제 운영 데이터 손상 사례를 확인한 것은 아니다.

## Expected behavior

결과 조회 실패를 정상적인 빈 조사 결과와 구분해서 안내한다. 저장된 계획은 계속 사용할 수 있어야 한다.

## Acceptance Criteria

- [ ] 해석할 수 없는 저장 결과에 대해 계획자 화면에 오류 안내가 나온다.
- [ ] 정상 결과와 지원하는 이전 형식은 기존처럼 표시된다.
- [ ] 실패한 읽기만으로 원본 결과를 덮어쓰거나 자동 유료 조사를 실행하지 않는다.
- [ ] 공유 화면에는 결과 본문이나 내부 오류 정보가 노출되지 않는다.
- [ ] 읽기 실패와 정상·이전 형식의 회귀 검증이 있다.
