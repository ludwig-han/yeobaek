# 005. [chore] 내 계획 목록과 수정 권한 복구의 브라우저 회귀 검증

번호: 로컬 #005
상태: Open

유형: chore / test

## Background

‘내 계획’은 브라우저 저장소와 서버의 수정 키 확인이 함께 동작해야 한다. 서버 요청 테스트만으로 브라우저에서 목록이 다시 열리는지 확인하기 어렵다.

## Current behavior

기준 커밋: `db82c3d`. 자동 테스트는 서버의 권한 복구와 HTML을 확인한다. 실제 JavaScript 실행, localStorage 저장·읽기 실패, 새 세션에서 목록을 통한 재진입은 브라우저 자동 검증에 포함되어 있지 않다. 기존 README에는 수동 확인 기록이 있다.

## Acceptance Criteria

- [ ] 계획 생성 후 같은 브라우저의 목록에 표시되고 다시 열 수 있다.
- [ ] 목록을 유지한 채 세션이 사라져도 올바른 키로 수정 권한을 복구한다.
- [ ] 제목 수정 후 목록 정보가 갱신된다.
- [ ] 공유 링크 열람만으로 목록이나 수정 권한이 생기지 않는다.
- [ ] 브라우저 저장소를 사용할 수 없을 때 안내가 나오고 서버의 계획 저장은 유지된다.
- [ ] 반복 실행 가능한 브라우저 검증과 실행 명령이 있으며 실제 Gemini 호출을 요구하지 않는다.

목록 기능 확장과 회원가입·기기 간 동기화는 범위 밖이다.
