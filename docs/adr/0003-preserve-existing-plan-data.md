# 0003. 입력 변경 시 기존 계획의 의미 보존

현재 구현을 기록한 ADR. 당시 논의나 대안 평가를 복원한 문서는 아니다.

## Context

자유 메모 중심 계획에 구조화 입력이 추가됐고, 이후 입력 항목이 줄었다.
기존 계획에는 새 화면에서 묻지 않는 선호와 시간 범위가 남아 있다.

근거: `d3a4cff`, `89fa397`, `d3a8c94` 및 V2·V4·V5 migration.

## Decision

기존 메모와 선호를 보존하고, 스키마 변경은 새 Flyway migration으로 추가한다.
새 고정 시각은 별도 값으로 두며 기존 시간 범위를 예약 시각으로 추정해 옮기지 않는다.
신규 Priority 제한이 줄어도 기존 추가 후보는 편집·저장할 수 있게 유지한다.

## Consequences

새 계획과 기존 계획이 사용하는 입력이 완전히 같지는 않다.
편집과 migration 변경 시 과거 데이터의 보존을 함께 검증해야 한다.
화면에서 입력을 제거한 것만으로 해당 저장 필드를 삭제할 수는 없다.
