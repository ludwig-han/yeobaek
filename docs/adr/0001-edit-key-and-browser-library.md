# 0001. 수정 키와 브라우저 내 계획 목록

현재 구현을 기록한 ADR. 당시 논의나 대안 평가를 복원한 문서는 아니다.

## Context

계획 공유와 수정 권한을 구분해야 한다. 기존 제품 기록은 회원가입·기기 간 연동 없이
같은 브라우저에서 계획을 다시 찾는 범위를 명시한다.

근거: `6852086`, `6560120`, `docs/PRODUCT.md`의 브라우저 내 계획 목록 Decision Log.

## Decision

조회 ID와 수정 키를 분리하고, 서버에는 수정 키의 해시만 저장한다.
수정 키 확인으로 세션의 수정 권한을 복구한다. 브라우저에는 목록과 수정 키를 보관하고
계획 본문은 서버 DB에 유지한다. 공유 화면 열람만으로는 목록에 추가하지 않는다.

## Consequences

다른 브라우저에서는 계획 주소와 수정 키가 필요하다. 브라우저 저장소를 지워도 서버의 계획은 남는다.
공용 브라우저에 보관된 키는 다른 사용자가 사용할 수 있다. 키 분실 복구나 계정 기반 목록은 제공하지 않는다.
